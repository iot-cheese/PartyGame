# PartyGame (サメゲー)

パーティーゲーム集アプリです。友達や家族と一緒に楽しめる様々なミニゲームを収録しています。

## 収録ゲーム

- **サメくん数え**: サメを数えるゲーム
- **おじいちゃん・おばあちゃん当て**: 画像を見て判別するゲーム
- **絵しりとり**: 絵で繋げるしりとりゲーム
- **都道府県当て**: 都道府県の形を当てるゲーム
- **ワードウルフ**: 誰が違うお題かを見つけるゲーム
- **シークレット質問**: 質問に答えるゲーム
- **罰ゲームルーレット**: 罰ゲームを決めるルーレット
- **フラッシュ暗算**: 瞬間的な計算力を試すゲーム
- **センス○×ゲーム**: センスを問うクイズ
- **5秒でストップ**: タイミングを競うゲーム
- **トンボよ止まれ**: 指でトンボを止めるゲーム
- **友達ゲーム**: 協力と裏切りのゲーム
- **音階当て**: 音階を聞き分けるゲーム
- **下ネタを作るな**: 言葉選びゲーム

## 開発環境

- Swift 5.0
- iOS 15.0+
- Xcode 14.0+
